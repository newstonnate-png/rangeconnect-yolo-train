# rangeconnect-yolo-train

Vast.ai training template for the RangeConnect bullet-hole detector. Rents a GPU,
pulls the dataset from Roboflow, trains a YOLO model, exports ONNX, and pushes
the weights to a private HuggingFace repo. Inference then runs 100 % on CPU in
`GunRangeApp3/scoring_app.py`.

**No image to build.** It rides the official `ultralytics/ultralytics:latest`
image plus `scripts/provision.sh`.

## What you need

- A Vast.ai account + `vastai` CLI.
- A **Roboflow** account with the `justines-workspace-ls3un` dataset. The
  API key is free; dataset export is a free-tier feature.
- A **HuggingFace** token + a (private) model repo name for the artifacts.

## Run a training job

1. Edit `Template/rangeconnect-yolo-train.md`: set the GitHub repo URL in the
   on-start line and fill real values for `ROBOFLOW_API_KEY`, `ROBOFLOW_VERSION`,
   `HF_TOKEN`, `HF_MODEL_REPO`, `JUPYTER_TOKEN`.
2. Create the Vast instance:
   - Image `ultralytics/ultralytics:latest`, launch mode **docker ENTRYPOINT**,
     40 GB disk, one RTX 3090/5090.
   - Paste the on-start script and the env one-liner from the template file.
3. The instance clones this repo and runs `scripts/provision.sh`:
   `deps → fetch_dataset.py → train.py (+ ONNX export) → upload_artifacts.py →
   JupyterLab on :8888`.
4. When `results.png` looks converged and `best.onnx` is in the HF model repo,
   `vastai destroy` the instance.

## Config

`train_config.yaml` holds the defaults; any env var (`MODEL`, `IMGSZ`, `EPOCHS`,
`BATCH`, `PATIENCE`, `DEVICE`, `CACHE`, `RUN_NAME`) overrides its key. See
`docs/MODEL_NOTES.md` for model + resolution guidance and
`docs/ADDING_CAMERA_FRAMES.md` for the dataset-improvement loop.

## Local dry run (no GPU)

```
pip install ultralytics onnxruntime pyyaml
# put a handful of images+labels in datasets/bullet-hole/train/{images,labels}
MODEL=yolo11n.pt EPOCHS=1 IMGSZ=320 python scripts/train.py
```
Confirms the wrapper, config parsing, and ONNX export path before spending GPU
time. (`data/bullet-hole.yaml` ships as a placeholder pointing at
`datasets/bullet-hole/`; `fetch_dataset.py` overwrites it with absolute paths on
a real run.)

## Layout

```
train_config.yaml            defaults, env-overridable
data/bullet-hole.yaml        YOLO data config (regenerated by fetch_dataset.py)
scripts/provision.sh         Vast on-start entrypoint
scripts/fetch_dataset.py     Roboflow (default) or HF dataset pull + val split
scripts/make_val_split.py    deterministic 85/15 split when the export has no val
scripts/train.py             ultralytics train + ONNX export
scripts/upload_artifacts.py  push weights/onnx/plots to a private HF model repo
Template/                    raw Vast launch config (hand-edited, source of truth)
docs/                        model notes + dataset loop
```
